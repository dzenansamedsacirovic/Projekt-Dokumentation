# GitHub-Funktionen

## Repository

Speicherung und Versionsverwaltung von Dateien.

## Gist

Speicherung und Freigabe von kleinen Codeabschnitten.

## Wiki

Erstellung und Verwaltung von Dokumentationen.

## Projects

Organisation von Aufgaben mithilfe eines Kanban-Boards.

## Issues

Verwaltung von Aufgaben, Fehlern und Verbesserungsvorschlägen.

## Milestones

Zusammenfassung mehrerer Issues zu einem gemeinsamen Ziel.

## GitHub Pages

Veröffentlichung von statischen Webseiten aus einem Repository.
