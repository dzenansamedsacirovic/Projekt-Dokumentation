# Projekt einrichten

## Voraussetzungen

- GitHub-Konto
- Git
- Visual Studio Code

## Einrichtung

1. Repository auf GitHub erstellen.
2. Repository mit einer README-Datei initialisieren.
3. Repository lokal klonen.
4. Repository in Visual Studio Code öffnen.
5. Ordner und Dateien erstellen.
6. Änderungen committen und pushen.
7. GitHub Pages aktivieren.

## Repository klonen

```bash
git clone https://github.com/dzenansamedsacirovic/Projekt-Dokumentation.git
```
